두산 매니퓰레이터 · E0509 · 유선 LAN

로봇 모니터링

LAN 연결 설정

서버 환경변수로 관리
  1. 유선 LAN 연결Mac과 E0509 제어기를 케이블로 연결하고 두 장비의 유선 IP를 같은 서브넷에 설정합니다.
  2. 모니터링 시작저장소 루트에서 Docker Compose를 실행하면 웹 UI와 rosbridge가 시작되고 제어기의 관절각을 읽습니다.
  3. 실장비 제어 연결SDK 접속 검사에 성공하면 작업 공간을 확인한 뒤 hardware 프로필을 시작합니다.
환경변수와 실행 명령

프로젝트 .env에서 제어기 주소와 ROS 네임스페이스를 설정합니다. 기본 Compose의 브리지 이름은 rosbridge이며, Linux host 구성에서는 127.0.0.1을 사용합니다.


              
모니터링과 관절 수신을 시작합니다.

              
docker compose up -d --build --wait

              
제어권 요청 없이 SDK 접속을 검사합니다. 성공하면 DRCF 버전과 6축 각도가 출력됩니다.

              
docker compose --profile hardware build doosan-driver
docker compose run --rm --no-deps doosan-driver timeout 15 check-e0509

              
실장비 드라이버는 시작할 때 제어권을 강제로 요청합니다. 승인되면 기존 보유자가 제어권을 잃고 서보가 켜질 수 있습니다. 작업 공간을 확인한 뒤 실행하세요.

              
docker compose --profile hardware up -d --build --wait --wait-timeout 150
